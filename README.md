
# 🛍️ Customer Shopping Behavior Analysis

## 📌 Project Overview

This project focuses on analyzing customer shopping behavior to uncover purchasing patterns, customer preferences, revenue trends, and subscription behavior. The analysis was performed using Python for data preparation, SQL Server for business analysis, and Power BI for interactive dashboard development.

The goal of this project was to transform raw customer transaction data into meaningful business insights that can support data-driven decision-making.

---

## 🎯 Business Objectives

* Analyze customer purchasing behavior
* Identify high-value customer segments
* Understand subscription patterns
* Evaluate revenue performance across categories
* Discover customer demographics influencing sales
* Generate actionable business recommendations

---

## 📂 Dataset Information

* Total Transactions: **3,900**
* Features: **18**
* Missing Values: **37 (Review Rating Column)**

Dataset contains:

* Customer Demographics
* Purchase History
* Product Categories
* Subscription Status
* Payment Information
* Shipping Preferences
* Review Ratings

## 💡 Key Insights

* Non-Subscribers contribute approximately 73% of customers and revenue.
* Young Adults generate the highest revenue.
* Loyal Customers represent the largest customer segment.
* Clothing-related products drive the majority of sales.
* Average spending remains similar between subscribers and non-subscribers.
